# World Population — fixed 3-column layout

Исправлена проблема с перекрытием:
- левая колонка имеет фиксированную область;
- центральная колонка получает только оставшееся пространство;
- правая статистика больше не накрывает глобус;
- размер Globe рассчитывается по реальной ширине/высоте центральной колонки;
- Canvas и контейнер Globe ограничены 100% центральной области;
- на мобильном ширина становится 100%, а глобус получает отдельную высоту.

После замены файлов:
npm install
npm run dev

Если Vite уже запущен — Ctrl+C и снова npm run dev.
